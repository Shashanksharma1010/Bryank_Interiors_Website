# Bryank Interiors Website (SPA)

## 🌐 Project Overview
Developed a **JavaScript-powered Single Page Application (SPA)** to showcase **Bryank Interiors' portfolio**. The website provides a seamless and engaging user experience with dynamic content rendering, enhancing the brand's online presence.

## 🎯 Features
- Single Page Application Architecture
- Dynamic Content Rendering
- Interactive User Interface
- Modern and Responsive Design
- Smooth Navigation
- Portfolio Showcase

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Tailwind CSS
- Git (Version Control)

## 📌 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shashanksharma1010/Bryank_Interiors_Website
.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Bryank_Interiors_Website

   ```
3. Open **index.html** in your browser to view the website.
